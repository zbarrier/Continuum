# Continuum.Persistence

Storage-agnostic foundation for Continuum state persistence. It is a placeholder for shared persistence types and currently contains no public API.

## Install

```
dotnet add package Continuum.Persistence
```

For grain state storage, use a provider such as [Continuum.Persistence.Orleans.KurrentDB](https://www.nuget.org/packages/Continuum.Persistence.Orleans.KurrentDB).
