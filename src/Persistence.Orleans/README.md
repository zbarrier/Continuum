# Continuum.Persistence.Orleans

[Microsoft Orleans](https://learn.microsoft.com/dotnet/orleans/) foundation for Continuum grain state persistence providers, built on [Continuum.Persistence](https://www.nuget.org/packages/Continuum.Persistence). It is a placeholder for shared Orleans persistence types and currently contains no public API.

## Install

```
dotnet add package Continuum.Persistence.Orleans
```

For grain state storage, use a provider such as [Continuum.Persistence.Orleans.KurrentDB](https://www.nuget.org/packages/Continuum.Persistence.Orleans.KurrentDB).
